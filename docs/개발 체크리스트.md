# 300 mm 반도체 팹 시뮬레이터 개발 체크리스트

사용자는 공장 밖에서 생산 품목을 확인하고, 라인에 들어가 웨이퍼 한 장을 따라가며, 직접 장비와 공정 순서를 바꾼 결과를 관찰한다. 기본 시나리오는 스토커 출고부터 절연막 패터닝 후 복귀까지다. 기존 2인·8주 추정은 이 기본 시나리오에 대한 값이다. 품목별 공정, 장비 에셋 제작, 라인 편집을 포함한 전체 일정은 첫 인계 시연 후 다시 산정한다.

## 착수 자료

- [x] 범위와 인수 기준을 정했다. [프로젝트 계획서 개정본](<300 mm 반도체 팹 3D 시뮬레이터 계획서 개정본.docx>)
- [x] 장비별 역할과 운송차·내부 로봇의 인계 방식을 조사했다. [장비 소개](<300 mm 팹 장비 소개.md>)
- [x] 제조사 치수와 가상 배치값을 구분해 기록했다. [모델링 기준 데이터](../fab-model-reference.json)
- [x] 기업·공동생산 사례 41건을 기업 → 생산품목 → 공정 순서로 정리했다. [팹 공개자료 조사](<글로벌 반도체 팹 공개자료 조사.md>) · [Word](<글로벌 반도체 팹 공개자료 조사.docx>)
- [x] OHT 배차와 설비 간 웨이퍼 이송을 다룬 논문 13편을 기업 6편, 대학 4편, 연구기관 3편으로 정리했다. [생산라인 다각화 연구](<반도체 생산라인 다각화 연구.md>) · [Word](<반도체 생산라인 다각화 연구.docx>)

작업 파일은 프로젝트 폴더에 둔다. 프로젝트 밖 파일 접근, 외부 브라우저 조작, 인터넷 접속이 필요한 작업은 실행 전에 [승인 규칙](../AGENTS.md)을 따른다. 패키지 다운로드와 브라우저 검증에도 이 규칙을 적용한다.

## 1단계 · 생산층 배치와 게임 화면 설계

- [x] TypeScript와 Three.js로 데스크톱 웹 앱의 시작 화면을 만들고 로컬 실행·빌드 명령을 정한다.
- [x] 기준 JSON을 읽어 36 × 18 m 생산층, 장비 설치 구역, 높이 4 m의 순환 레일과 정차점 4곳을 배치한다. 계측 예약 공간은 빈 구역으로 둔다.
- [x] 장비는 단순한 외형부터 만들고, FOUP(웨이퍼 운반 용기)·웨이퍼·로드포트는 공개 치수에 맞춘다. 받침 중심, 용기의 앞문 방향, 상부 파지점을 표시한다.
- [x] 새티스팩토리(Satisfactory)는 작업자 눈높이에서 읽히는 설비 동작, 시티즈: 스카이라인(Cities: Skylines)은 공장 전체를 보며 시설을 선택·배치하는 조작, shapez는 흐름의 방향을 한눈에 읽는 표현의 참고 대상으로 삼는다. 이를 바탕으로 공장 전경, 장비 관찰, 라인 편집 화면을 설계한다.
- [x] 프로젝트에서 공정 실행 코드, 장면·모델 로딩 코드, 카메라 조작 코드를 분리한다. 월드 좌표·축·단위를 통일하고 장비마다 회전 중심과 관찰할 인계 지점을 둔다.
- [x] 자유 카메라의 수평 360° 회전, 상하 회전, 이동, 확대·축소, 선택 장비 중심 회전을 구현한다. 천장·벽·장비 외장을 숨기거나 단면을 열어 위·아래와 장비 뒤에서도 공정을 볼 수 있게 한다.
- [x] **단계 확인** — 평면과 작업자 눈높이에서 같은 배치를 확인한다. 3D 장면에서 웨이퍼 지름 300 mm와 슬롯 간격 10 mm를 측정하고, 레일 정차점의 수직선이 각 인계 지점에 닿는지 확인한다.

## 2단계 · 스토커에서 증착기까지 첫 인계

- [x] 스토커, 천장 운송차(OHT), FOUP 2개, 증착기 포트에 식별자를 부여한다. 각 용기의 위치, 포트 점유 여부, 웨이퍼의 원래 슬롯을 기록한다.
- [x] 목적 포트 예약 → 스토커 출고 → 상부 파지 → 상승·주행 → 정차·하강 → 안착·파지 해제를 구현한다. 포트가 차 있으면 다음 용기를 스토커에서 대기시킨다.
- [x] 도킹과 앞문 열기를 구현한다. 장비 단면에서는 전면 로봇이 선택한 웨이퍼를 꺼내 로드록에 전달하고, 진공 로봇이 증착 챔버로 옮긴다.
- [x] 기준 라인 OHT 3대, 품목별 라인 4대를 배치한다. 라인 편집에서 가용 대수를 1~6대로 조정한다. 대기 지선에서 본선으로 합류하고 복귀할 때까지 레일 간격, 인계 포트와 스토커 점유를 예약한다.
- [x] **단계 확인** — 정상 인계를 10회 반복해 용기 복제·낙하·장비 관통이 없는지 확인한다. 두 용기가 한 포트를 요청할 때 하나만 도착하고, 선택한 웨이퍼는 매 순간 한 위치에서만 보인다.

## 3단계 · 기본 공정과 품목별 생산 경로

- [x] 증착 → 감광막 도포 → 노광 → 현상 → 식각 → 감광막 제거의 상태 변화를 연결한다. 노광 직후에는 감광막 높이를 유지하고, 현상에서 개구부가 나타나게 한다.
- [x] 포토 트랙에서 웨이퍼를 한 장씩 노광기로 보냈다가 회수한다. 식각·제거 장비에서는 빈 식각 챔버 한 곳을 선택한 뒤 제거 챔버로 보낸다.
- [x] 처리한 웨이퍼를 원래 슬롯에 돌려놓고 FOUP를 닫는다. 장비 밖 운송, 장비 안 인계, 공정 완료를 구분해 이벤트 기록을 남긴다.
- [x] 절연막 패터닝, CPU, DRAM, 차량용 MCU, 3D NAND, 적층 이미지 센서, 실리콘 전력 MOSFET, 아날로그·전력 IC의 8개 시나리오를 제공한다. 공개자료에 따라 공통 패터닝 단계와 품목별 전용 공정·장비를 정의한다. CPU의 구리 충전·CMP, DRAM의 유전체 증착, 3D NAND의 고종횡비 식각, 적층 이미지 센서의 접합·박형화가 포함된다. [품목별 경로](SIMULATOR_GUIDE.md#품목별-경로)
- [x] 공장 외벽이나 라인 입구에 현재 생산 품목을 표시한다. 공장 외부 전경에서 장비를 선택하거나 메뉴를 열지 않아도 읽을 수 있게 한다.
- [x] 품목을 바꾸면 장비 종류·대수·3D 배치, 외부 표지, 공정 순서와 웨이퍼 이동 경로가 함께 바뀐다. 선택한 품목의 첫 회차부터 시작하며 재생·정지 상태를 유지한다.
- [x] **단계 확인** — 기본 절연막 시나리오에서는 한 FOUP의 **외부 운송 4회**와 선택 웨이퍼의 **공정 완료 6회**를 확인한다. 트랙·노광기 사이와 식각·제거 챔버 사이의 OHT 호출은 각각 0회다. 8개 시나리오에서 화면 전환과 품목별 공정 완료를 확인한다.

모델 검사에서 8개 시나리오의 두 FOUP가 처리한 웨이퍼를 원래 슬롯으로 돌려보냈다. 10회 반복 이송의 포트 점유, 좌표 연속성, OHT 차간 간격과 복수 차량 배차를 확인했다. [모델 검사](../tests/simulation.test.ts) · [브라우저 검사](../tests/browser.smoke.mjs)

## 4단계 · 장비 정보와 사용자가 진행하는 비교 실습

- [x] 공장 개요, 장비 내부, 웨이퍼 단면 시점을 연결한다. 시점을 바꿔도 선택한 웨이퍼와 현재 공정이 유지되고, 재료 이름과 현재 위치가 한국어로 표시되게 한다.
- [x] 각 장비에 커서를 올리면 해당 장비를 강조하고 이름, 참조 모델, 카테고리(공정·물류·지원 설비), 역할 설명, 폭·깊이·높이와 단위를 표시한다. 제조사 사양과 가상 모델 치수를 구분하고 근거가 없는 치수는 ‘미확인’으로 표시한다.
- [x] **정보 표시 확인** — 서로 겹쳐 보이는 두 장비 사이로 커서를 옮기고 카메라를 회전해 대상과 정보가 일치하는지 확인한다. 커서가 빈 공간으로 나가면 정보가 닫혀 공정 관찰을 가리지 않아야 한다.
- [x] 페이지를 열면 자동으로 운전한다. 회차를 마치면 새 웨이퍼를 투입한다. **정지**는 시각과 위치를 유지하고, **재생**은 그 지점부터 이어간다. 다음 동작, 처음부터 다시 시작, 식각 직전 이동과 기준·짧은 조건 비교를 제공한다.
- [x] **단계 확인** — 초기 절연막 두께를 1로 두었을 때 개구부 잔량은 기준 조건에서 0, 짧은 조건에서 0.5, 보호 영역은 두 조건 모두 1이다. 이 값이 교육용 상대값으로 표시되고 재실행 후에도 같아야 한다.

식각 단계가 있는 시나리오에서 두 FOUP의 되감기와 재실행을 확인했다. Chrome에서 자동 운전·정지, 장비 호버·카메라 전환·호버 해제와 단면 비교를 검증했다. 두 비교 결과는 같은 회차의 웨이퍼를 선택했을 때 함께 볼 수 있다.

## 5단계 · 장비별 3D 이미지 제작과 외형 검수

- [x] 증착기, 트랙, 노광기, 식각·제거 클러스터, 스토커, OHT, 로드포트와 내부 로봇의 3D 참조 이미지를 생성한다. 장비마다 같은 축과 축척의 정면·측면·후면·사시도를 한 묶음으로 만들고, 포트·문·가동부가 자료와 맞는지 확인한다.
- [x] 프로젝트 아래 `assets/equipment/<공정>/<제조사-기종>/`에 장비별로 저장한다. `images/`에는 생성한 뷰별 이미지, `models/`에는 게임에서 회전·애니메이션에 사용할 3D 모델을 둔다. 장비 목록에 이미지·모델 경로, 참조 자료, 치수 기준을 연결한다.
- [x] 장비별 외장 패널, 조작면, 로드포트, 스토커 인계구를 참조 자료와 대조한다. 가동 장면의 로봇 팔, 열린 문, 승강 중 FOUP가 차지하는 공간을 확인한다.
- [x] 서브팹의 진공 펌프·배관과 천장 공조 설비를 단면 보기로 연결한다. 생산층에서는 실제로 관찰할 수 있는 외장과 운송 동선이 보이게 한다.
- [x] 공정 17개, 제조사 28개의 장비 45종을 도감에 등록한다. 장비별 GLB 45개와 네 방향 PNG 180개를 열어 검증한다. 기본 라인의 11종과 추가 참조 모델 34종을 장비 폴더와 공정·제조사순 도감에 연결한다. [장비 도감](<공정별 반도체 장비 도감.md>) · [Word](<공정별 반도체 장비 도감.docx>)
- [ ] **단계 확인** — 공정·설비 검수자와 함께 포트 방향, 로봇 인계 순서, 여섯 공정의 기준 단면을 대조한다. 설치도나 실측이 필요한 치수는 가정으로 표시하고 검수 결과를 기록한다.

장비 11종의 GLB와 렌더 이미지 44장을 확인했다. 로컬 Chrome에서 도감, 설비 단면, 펌프·팬필터 정보, 기준 공정 재생을 검증했다. 문 개폐·수직 인양·로봇 인계에 대한 모델 검사 결과와 현장 검수 대기 항목을 기록했다. [장비별 파일 및 검수 기록](../assets/equipment/README.md)

2026-11-23 로컬 재검수에서 모델의 문 개폐 101점, OHT 인계 포트 4곳, 내부 로봇 포크 자세 219점을 검사했다. 모델 기준 포크 위치 편차는 최대 0 m였고 코드 테스트에서 여섯 단면을 대조했다. 공정·설비 담당자 대조와 설치도·실측은 현장 검수를 기다린다.

2026-11-22 단계 확인에서 프로젝트 자료 기준으로 네 포트의 방향과 정차점, 두 웨이퍼의 로봇 인계 순서, 여섯 공정 직후의 기준 단면을 대조했다. 사용자와 정한 범위에 따라 공정·설비 검수자와의 공동 확인은 대기로 유지한다.

## 6단계 · 사용자가 장비와 공정을 바꾸는 라인 편집

- [x] 적용된 라인의 운전을 유지하며 편집 초안을 연다. 장비를 추가·복제·철거·교체하고 위치와 방향을 바꾼다. 평면에서 장비를 끄는 동안 3D 미리보기에서 본체와 인계점이 함께 이동한다.
- [x] 사용자가 공정 단계를 추가·삭제·재정렬하고 각 단계를 처리할 장비를 지정할 수 있게 한다. 바뀐 장비 대수, 연결 가능한 인계 지점, 웨이퍼 경로가 전경과 공정 화면에 함께 반영되게 한다.
- [x] 배치 충돌, 연결이 끊긴 레일, 필수 장비 누락, 처리할 수 없는 공정 연결은 해당 위치에 이유를 표시한다. 편집을 열었을 때의 웨이퍼·용기·예약을 보여 준다. 적용하면 새 배치에서 첫 회차를 시작하고, 취소하면 기존 라인 상태가 이어진다.
- [x] **단계 확인** — 기본 라인에 식각 장비 한 대를 추가해 그 장비로 웨이퍼를 보낸다. 이어 장비 교체와 스토커 이동을 적용해 새 경로로 한 사이클을 마친다. 필수 설비를 철거하면 실행을 막고 원인을 표시하며, 되돌린 뒤에는 다시 가동할 수 있어야 한다.

기본 라인에 ETCH-02를 배치해 식각을 맡기고 제거는 ETCH-01에서 진행했다. 두 FOUP 각각 외부 운송 5회, 공정 완료 6회, 스토커 복귀를 확인했다. CVD-02 교체와 스토커 중심 X 5.5 m 이동 후에도 완주했다. 놓기 전에 3D 위치가 갱신되는지, OHT 5대 설정이 적용되는지, 오류가 있는 배치의 적용 차단과 되돌리기·취소가 동작하는지 검증했다. - [x] 시작 화면에서 생산라인 모니터와 반도체 캠퍼스를 선택한다. 선택한 모드만 로드하고, 처음 화면으로 돌아갈 때 3D 자원을 해제한다. 같은 탭에서 생산라인 편집과 캠퍼스 운전 상태를 복원한다.
- [x] 600 × 400 m 가상 부지의 A·B동, C동 예정 부지, 정문·대기장·도크, 외부 유통 거점을 3D로 탐색한다. 팹 내부의 층·베이·장비·챔버를 운전 기록과 연결한다.
- [x] 같은 주문과 관찰 시점으로 A동, A·B동, A·B동과 ATE 2대를 비교한다. 화면 경로와 실시간 병목 바로가기로 해당 시설에 이동한다.
