# FAB CONTROL 입문자 실습

## 참가자용

시뮬레이터의 첫 화면에서 시작합니다. 아래 작업을 순서대로 수행한 뒤 마지막 두 질문에 자신의 말로 답해 주세요. 제한 시간은 10분입니다. 결과를 찾았으면 진행자에게 알려 주세요.

1. 공장 **입구**에서 표지에 표시된 생산 품목을 확인하세요. **CPU**를 선택해 표지가 어떻게 바뀌는지 보고, 실습을 위해 **절연막 패터닝**으로 돌아오세요.
2. 장비 정보에서 포토 트랙의 역할을 찾으세요. **FOUP-02**를 선택해 재생하거나 **다음 동작**으로 진행하면서, 용기를 옮기는 동작과 웨이퍼 한 장을 옮기는 동작을 각각 한 번 관찰하세요.
3. **웨이퍼 단면**에서 같은 웨이퍼를 **기준 시간**과 **짧은 시간**으로 식각하세요. 두 결과에 표시된 개구부와 보호 영역의 잔량을 적고 **처음부터**로 돌아오세요.
4. FOUP 운송과 장비 내부 웨이퍼 낱장 이송은 무엇을 어디로 옮기나요? 이번 시뮬레이션에서 짧게 식각했을 때 개구부에 절연막이 남은 이유는 무엇인가요?

## 진행자용

입문자 다섯 명에게 참가자용 부분만 제시한다. 같은 배포 빌드를 새로고침해 기준 시나리오를 열고, 사용 환경과 시작 시각을 기록한다. 과제를 제시한 시점부터 마지막 답을 마친 시점까지 잰다. 관찰 중 화면 조작이나 답변에 대해 안내했다면 제공한 도움을 기록한다. 참가자는 이름 대신 01~05로 표기한다.

**완료**는 시간 10분 이내, 도움 없이 세 조작 과제 수행, 두 질문의 개념 설명을 모두 충족한 경우다. 다섯 명 중 네 명 이상 완료가 인수 기준이다.

- FOUP는 웨이퍼를 담은 상태로 장비·스토커의 포트 사이를 이동한다. 낱장 이송은 로봇이 FOUP 슬롯에서 꺼낸 한 장을 챔버나 인접 노광기로 넘긴다.
- 짧은 조건의 처리 시간은 기준의 절반이라 모델에서 개구부 절연막이 일부 남는다. 기준의 개구부 잔량은 0, 짧은 조건은 0.5이며, 감광막으로 보호된 영역의 잔량은 모두 1이다. 잔량은 교육용 상대값이다.
